# Alshiya & Baba — Ultra Premium Wedding Invitation

Open `index.html` in a modern browser.

## Included
- Cinematic full-screen opening
- Scroll-driven reveal transitions
- Parallax hero
- Editorial typography
- 3D hover/tilt cards
- Invitation gallery using the supplied invitation photographs
- Both event dates and venues
- Google Maps navigation buttons
- Embedded venue maps
- Assistance phone section below the map/navigation area
- Responsive mobile layout
- Reduced-motion accessibility support
- No music/audio

## Important
The invitation images do not show a clear assistance phone number. The site therefore contains a placeholder:

+91 00000 00000

Replace it in `index.html` in the `.assistance` section with the real number.

The Google Maps URLs are search/navigation URLs based on the venue names and addresses printed on the invitation. If the family has exact Google Maps place links, replace the two map URLs for maximum accuracy.

For deployment, upload the whole folder to any static host such as GitHub Pages, Netlify, Vercel, or your existing hosting.
